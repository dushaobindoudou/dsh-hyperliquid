## 接下来还需要完成

1. **真实 Web 会话验收**：从票据输入原因、agent 决策/下单、交易所或 paper 回执，到钱包与图表标记，用同一会话走完整路径。现有自动化覆盖了页面渲染、画线和宿主交易逻辑，尚不能代替此验收。
2. **订单状态与原因对账**：live 审计以 `cloid` 关联交易所历史订单；`cloid` 缺失的旧单、外部下单和部分保护子单不能显示本地原因。应把订单、成交、决策、保护单关系整理为稳定的本地交易日志，并提供异常回执对账入口。
3. **更多历史与准确收益**：官方 `historicalOrders` 和 `userFills` 各限最近 2000 条；需用 `userFillsByTime` 分页与本地归档扩展成交历史。收益图是官方采样值，不宜用于逐笔会计对账；后续应结合资金费、手续费、入出金提供可解释的净收益报表。
4. **实盘事件推送**：账户当前每 3 秒轮询，历史按需刷新。接入 `orderUpdates`、`userFills` 和账户 WS 事件后，可及时更新订单生命周期并减少 REST 权重。
5. **画线交互进阶**：现有两种线和撤销能覆盖基础标注；若要达到完整 TradingView 体验，还需线段拖拽编辑、延长射线、磁吸 K 线、更多工具及快捷键。当前交易标记对齐 K 线时间，价格在详情中显示；精确价格坐标标记可用 series primitive 实现。
6. **模拟盘与市场范围**：paper 仍未模拟深度、手续费、资金费、强平；现货、HIP-3、Outcome 仍只读。应先确定是否需要扩展这些市场，再设计交易规则与风险校验。
7. **主网前的验收门槛**：已注资 testnet 的 `normalTpsl` 保护单、不同账户模式和异常回执需端到端核对；主网使用前还要核对专用钱包、权限、限额和退出流程。

历史接口、收益口径和记录上限依据 [Hyperliquid Info API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint) 与 [Portfolio graphs](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/portfolio-graphs)。

## 交易判断还缺什么信息（2026-10-15 复核）

目前已有 K 线与技术指标、盘口/成交、标记价/预言机价、资金费、24h 成交额、未平仓量、账户/仓位/挂单，以及带原因的本地委托和成交记录。它们回答了“现在价格与账户怎样”，但还不能完整回答“刚才发生了什么、为什么变化、策略何时失效”。

1. **先做可核对的事件时间线**：把下单决策、提交、接受/拒绝、部分成交、撤单、资金费、强平和入出金按交易所时间串起来；保留来源、交易所 ID、会话、原因和数据时效。现有本地订单/成交账本可复用；后续接入官方 `orderUpdates`、`userEvents`、`userFundings` 与账本 WebSocket，并与历史接口对账。
2. **再补市场状态变化**：展示多个时间窗的成交量、资金费和未平仓量变化，以及买卖价差、盘口深度和大额成交；标明刷新时间，避免把单点 24h 数值误读为趋势。HIP-3 的市场状态需按各 DEX 读取。
3. **外部催化事件单独接入**：项目公告、交易所状态、宏观日历和相关新闻需要选定可核验的数据源；展示原始链接、发生/发布时间、关联标的和不确定性，不能把新闻摘要直接当作下单信号。当前插件尚无新闻或宏观事件源。
4. **下单前给出决策摘要**：交易依据、入场条件、失效条件、时间尺度、计划风险、预估手续费/资金费/滑点、账户敞口和数据新鲜度；没有足够数据时显示“未知”，并保持现有实盘预检与一次性授权。
5. **交易后复盘**：将原因与实际成交、费用、资金费、最大不利波动和结果关联，区分策略判断错误、执行偏差和外部事件。

HIP-3（如 `xyz:XYZ100`）在 Hyperliquid 上可交易，但插件目前只支持切换到该市场查看行情。开放下单需要按官方 `{dex}:{coin}` 元数据计算交易资产 ID，处理不同账户模式与 DEX 抵押资产，补齐可交易额度、价格/数量精度、风险校验、撤单和保护单，再分别通过 paper、testnet 和 live 验收；不能只把目录中的 `tradable` 改为 `true`。[官方资产 ID](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/asset-ids)、[账户模式](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/account-abstraction-modes)、[官方 WebSocket 数据流](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/websocket/subscriptions)。
