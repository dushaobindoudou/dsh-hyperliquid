# TradingView 对照与基础工具补齐

复核日期：2026-10-16。范围：当前源码、0.2.0 已通过的绘图冒烟，以及本次基础图表改动。

## 判断

目前已经具备单图看盘、常用技术分析、画线保存、成交原因复盘和会话协作的主体流程。与完整 TradingView 相比，主要差距在多图工作空间、指标和策略开发、历史回放、回测、筛选器、数据覆盖和云端提醒。不能用画线工具数量推导整体完成百分比。

当前采用 TradingView Lightweight Charts。它是图表渲染库；TradingView 网页产品、Advanced Charts 和 Trading Platform 提供的上层能力需要分别评估，安装 Lightweight Charts 不会自动获得这些能力。

## 已有与本次补齐

| 范围 | 原有实现 | 本次补齐 | 仍有边界 |
| --- | --- | --- | --- |
| 图表显示 | 蜡烛图、14 种行情周期、线性/对数/百分比刻度、放大 | 美国线、折线、面积、平均 K 线，图表类型随会话保存 | 未实现 Renko、Kagi、成交量蜡烛等特殊聚合 |
| 导航 | 拖动/缩放、向左补历史、视区保存、复位 | 最近 1/5/30 天、已加载全部、按日期补历史并定位、回到最新 | 受交易所数据窗口和本地加载上限限制；“全部”指已加载数据 |
| 画线 | 40 类工具、磁吸、连续绘制、样式、拖动、锁定/隐藏、复制、撤销重做、列表、会话同步和保存 | 收藏常用画线，快捷工具栏，精确编辑时间/价格/名称，操作帮助 | 复杂图形的高级参数、图层分组和批量管理仍可加强 |
| 指标 | 成交量、SMA20/60、EMA20/50、BOLL、RSI、MACD，最多 8 条可配置均线（SMA/EMA/SMMA/WMA） | ATR14 副图、UTC 日内 VWAP、指标及成交量随十字光标更新 | RSI/MACD/BOLL 参数目前固定；无 Pine 或自定义脚本运行时 |
| 导出 | 无统一导出入口 | PNG 含画线/成交点/指标，CSV 导出已加载原始 OHLCV（UTC） | 不等于全市场历史下载；PNG 不包含弹窗或编辑控件 |
| 提醒 | 指定直线/趋势线价格穿越，单次触发，可重新开启 | 保留 | 无复杂组合条件、指标条件、独立云端运行和 webhook |
| 交易与复盘 | 账户、仓位/委托/成交、模拟盘、下单原因、图表成交点、统一限额、会话工具 | 保留 | 尚无标准策略回测、样本外评估、模拟盘口/手续费/资金费完整成本模型 |

平均 K 线仅改变画面；十字光标、会话引用、CSV 和交易继续使用交易所原始 OHLC，避免把合成价格当作成交价。

本轮同时修复了两个复核发现的问题：历史补取时的旧视区延迟保存会覆盖日期跳转结果；当前 DSH 的会话列表需要通过 `getSnapshot()` 读取，旧 `get()` 路径会漏掉列表就绪通知，造成刷新后偶发 `unknown session`。新增了精准的日期导航回归和刷新后的原生会话接入验收。放大图表的布局也为新增工具和底部导航保留了空间。

VWAP 使用 HLC3 × 基础币成交量，按 UTC 00:00 重置，属于 K 线近似 VWAP。首个交易日若缺少午夜开始的历史，不展示该日的不完整结果；开启指标时自动补取最新交易日历史。ATR14 使用与现有 `hyper_market indicators` 一致的 Wilder 初始化和平滑。

## 后续范围（已按用户选择收敛）

已选择的复盘可信度、多周期研究、指标参数与模板见 [本次实现与口径](research-review-2026-10-16.md)。下列为早前评估记录，历史回放、提醒平台和策略研究平台不再作为待办。

### 原评估记录

1. 交易复盘可信度：模拟成本、订单/成交对账、策略样本和执行偏差统计。
2. 多周期研究：双图/四图、标的/时间/十字光标联动，保存布局。
3. 历史回放：时间游标、逐根/自动播放、严格隔离未来数据和实盘执行。
4. 指标设置：RSI/MACD/BOLL 参数、指标模板与数据窗口，扩充 Stochastic/ADX/OBV 等常用指标。
5. 提醒服务：指标条件、重复规则、触发审计和通知渠道。
6. 策略研究平台：回测引擎、成本模型、样本外验证、参数敏感性；需要单独的设计与验证。

增加交易理论模板不等于证明策略有效。策略效果需要通过上述可重复的验证流程衡量。

## 验证

- `npm run typecheck`
- `npm test`（新增合成 K 线、ATR/VWAP 边界、原始点位引用、CSV 和工作台恢复测试）
- `npm run smoke:chart`（真实临时 DSH 宿主，图表切换/画线保留/光标读数/日期导航/PNG 像素/CSV/刷新恢复）
- `npm run smoke:drawing`（原有绘图交互、重启恢复与基础图表组合回归）
