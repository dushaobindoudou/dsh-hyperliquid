# 会话隔离与持续入场：0.6.0

需求来自本次用户对话。审查基点：`30b956c0424dc08bbd5b46a2d29eaa8a2ff5f387`。

- 每个交易会话至少持有一笔归属自己的成交仓位；其他会话的净仓和远价挂单不能算作入场。所有 live 工具开仓必须附止损，减仓仍可执行。
- 新会话的档案、策略和日志默认隔离。不提供启用交易的会话开关，入口仅为「共享会话」，用户可主动共享档案与策略规则或恢复独立；成交、计划、战绩与订单归属仍分别记录。不同市场可共享同一套规则。
- 同账户同合约可以存在多个同向会话份额；每个会话只能减自己的份额、撤自己的订单。反向策略因交易所净仓抵消而明确报告冲突，不伪装为两个独立仓位。账户级硬限额继续统一执行。
- 自动检查必须逐会话路由，同币种会话复用行情读取；2026-10-21 起只唤醒开启「盯盘」的会话（默认关闭；盯盘即自主交易；用户点按钮或在对话里让 agent 开启，自动轮不能自己开启），周期跟随本会话策略的入场周期（5m–4h，默认 15m），启动后第一根 K 线只记录基线，不补发唤醒。归档的会话不继续自动开新仓，恢复后继续自动检查。
- K 线画线、委托与成交标记、挂单严格按会话独立，任何共享方式下都不交叉展示。共享策略不共享成交记录与战绩。
- 共享方式只有两种：独立（默认）与全局共享（所有全局共享会话共用一套规则与档案）。2026-10-21 起取消「共享到指定会话」与画线同步，旧数据迁回独立。
- 旧全局日志按已记录的 sessionId 与 strategyId 迁移，未能确定归属的旧数据保留在原 journal.json，不自动混入新会话。共享规则的持久目录独立于聊天目录，移除来源会话不能删除其他会话正在使用的规则。
- 保留策略 skill 的按需引用和精简；同步 prompt、工具与唤醒文案。
- 发布新版 npm 包与 GitHub Release。构建、类型检查、针对隔离/订单/自动唤醒的测试和完整回归通过后发布；不执行真实资金交易来验收。

范围说明：这是同一交易账户内的归属与操作隔离，资金仍共享账户保证金。真正独立的反向仓位需要不同账户；本版不自动创建或注资子账户。
